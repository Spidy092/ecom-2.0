# Modern Grocery demo assets

The Modern Grocery starter uses twelve original generated product images. They
are bundled with the theme so the public Playground and local CI do not depend
on third-party media hosts.

Generated on 25 August 2026 with the OpenAI image generation tool using a
consistent product-catalog prompt: one unbranded grocery subject, warm paper
studio background, soft daylight, no text, logo, watermark, people, hands, or
competitor imagery. Each image was resized to a maximum 640px edge and saved as
WebP for the demo catalog.
