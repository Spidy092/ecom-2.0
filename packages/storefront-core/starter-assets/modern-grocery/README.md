# Modern Grocery canonical starter assets

This directory is the canonical distribution root for approved Modern Grocery starter/demo image assets.

Do not add image files directly without an approved entry in `release/demo-assets.json`.

The first planned batch is the six deterministic grocery fixture products documented in `docs/VISUAL-ASSET-STRATEGY.md`.

Customer-facing image files must not contain third-party logos, readable branded packaging or identifiable people unless separately reviewed and explicitly approved.
