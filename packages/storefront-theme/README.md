# BhaivaTech Grocery Alpha — Internal Block Theme

This is the presentation layer for the grocery-first WooCommerce engineering alpha.

## Boundary

The theme owns visual composition, tokens, templates, patterns and presentation styling. Grocery business behavior belongs in `storefront-core` and WooCommerce remains authoritative for products, cart, checkout, customers and orders.

The internal name is temporary. Do not publish this package as a customer-facing product until naming clearance is complete.
