# Round 2 Mobile Shopper Test Card

Use together with `session-kit.md`. This card is the short facilitator checklist.

## Participants

Use exactly one unique code per person:

```text
S05
S06
S07
S08
S09
```

## Device

Real mobile preferred, otherwise approximately 390 × 844 / 400 × 874 CSS pixels.

## Before task

- set participant code;
- group = `Shopper`;
- choose First-time or Repeat-shopper test;
- Reset run;
- close Test controls;
- do not explain Search, Aisles, Buy again, Saved, or Cart.

## First-time task

Use the exact fixed basket from `session-kit.md` and fixture postcode `560001`.

Before opening Cart, ask the participant to state what item count and total they think the Cart contains.

After task ask, before explaining:
- What does Saved mean?
- What does Cart mean?
- Are they clearly different?

## Repeat-shopper task

Before using the section ask:

> What do you think Buy again means here?

Then run the exact repeat-shopper mission from `session-kit.md`.

After task ask:
- What does Saved mean?
- What does Cart mean?
- How is Saved different from Cart?

## Required evidence

For every participant push both:

```text
research/users/participants/S0X.md
research/users/results/aisleflow-v0-round2/S0X.json
```

## Stop-and-fix rule

If two participants independently hit the same **major confusion or blocker**, stop the round, synthesize it, and revise the prototype before testing more people.
