# Anonymized Participant Notes

One Markdown file per participant, created from `../session-note-template.md`.

Use IDs only, for example:

```text
S05.md  shopper
B03.md  WooCommerce builder
O02.md  store owner
```

This repository is public. Do not include real names, contact details, addresses, private store/customer data, identifiable recordings, or other personal information.
