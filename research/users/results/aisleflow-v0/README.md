# AisleFlow V0 pilot session exports

These files are anonymous browser-local session exports from the AisleFlow V0 research prototype.

## Privacy boundary

Before adding an export here, verify that it:

- uses an anonymous participant code only (for example, `S04`), never a real name or contact detail;
- has `network_telemetry: false`;
- has `search_terms_recorded: false`;
- has `postcode_recorded: false`; and
- contains no free-text notes, recordings, screenshots, or other personal data.

The exporter records interaction events and built-in timing/surface metrics. It intentionally excludes entered search terms and postcode values. These raw exports do not substitute for researcher observation notes or a participant's consent for recordings.

See `research/users/aisleflow-v0-pilot-results-2026-08-18.md` for the preliminary synthesis and `research/users/session-kit.md` for the testing protocol.
