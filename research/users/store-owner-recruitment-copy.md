# Store-owner recruitment copy — Round 1

Use these as starting points. Adapt tone to the community, but do not add claims about ease, quality, conversion, performance or commercial validation.

## Short community post

**Looking for 5 WooCommerce store owners/builders for a short usability test**

I’m testing an early WooCommerce storefront setup/personalization experience and looking for people who currently run a WooCommerce store, build/manage WooCommerce stores for clients, or are actively evaluating WooCommerce for a real project.

The session uses a disposable browser-based demo store, so there is nothing to install and no production store access is needed. I’ll ask you to complete a few normal setup/customization tasks while I observe where the experience is clear or confusing.

No customer data, credentials or production configuration are needed. This is usability research, not a sales call.

If you’re interested, reply/DM and I’ll send a short qualification screener.
